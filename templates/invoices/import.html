Instruções
Como importar uma nota fiscal:
  1. Selecione o tipo de nota fiscal (entrada ou saída).
  2. Clique em "Escolher arquivo" e selecione o arquivo XML da nota fiscal.
  3. Clique em "Importar XML" para processar o arquivo.
  4. Após a importação, verifique os dados e, se necessário, faça ajustes.
Observações importantes:
  • O arquivo deve estar no formato XML oficial da SEFAZ (NF-e, CT-e).
  • Certifique-se de que o XML não está corrompido ou incompleto.
  • O sistema tentará criar novos registros para clientes, fornecedores e produtos não encontrados.
  • Após a importação, você poderá editar a nota fiscal para ajustar informações.
